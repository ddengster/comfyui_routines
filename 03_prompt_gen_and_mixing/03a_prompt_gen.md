
# Prompt generation

- Look up sources like pinterest, isolate and snip a picture of the thing you want

- Use ChatGPT, ask it to "give a stable diffusion prompt" while describing the picture.
eg. give a stable diffusion prompt for this picture of a fantasy soldier using a mace

- Plug the positive and negative into your Image Generation template's `Text Encode (Prompt)` nodes

- Follow up on chatgpt's suggestions. eg:

```
If you want, I can:

Match a specific art style (Studio Ghibli, Darkest Dungeon, Line Friends, RPG icons, etc.)

Optimize this for SDXL vs SD 1.5

Convert it into a LoRA-friendly prompt or icon / game asset format

```

- It's good to add/remove tags to see what results you can get
